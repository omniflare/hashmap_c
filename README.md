# Hash Table in C

A hash table implementation in C supporting **Separate Chaining** and **Double Hashing**.

## Acknowledgements

A big thank you to [James Routley](https://github.com/jamesroutley) for his excellent tutorial, [Write a Hash Table in C](https://github.com/jamesroutley/write-a-hash-table). This project started as a learning exercise based on his tutorial.

## Usage

| Command | Description |
|---|---|
| `make` | Build the hashmap |
| `make run` | Run the tests |
| `make benchmark` | Run benchmarks and generate `benchmark.md` |
| `make clean` | Remove generated binaries |
